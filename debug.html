F. Self-Produced Sequences
⏱2 seconds 💾512 megabytes 2000Candidate Master
*specialcombinatoricsmath

Let's call an integer sequence self-produced if for every iii (1≤i≤n1≤i≤n1 \le i \le n) at least one of the following conditions holds:

  • ai is equal to the sum of the elements on the left (i. e. ai=i−1∑j=1aj);
  • ai is equal to the sum of the elements on the right (i. e. ai=n∑j=i+1aj).

Note that 000 at the beginning/end of the sequence is also considered valid.

You are given an integer array aaa of size nnn. Your task is to calculate the number of self-produced subsequences of the array aaa. Since the answer might be large, print it modulo 998244353998244353998244353. Two subsequences are different if the indices of chosen elements are different.

Input

The first line contains a single integer ttt (1≤t≤1041≤t≤1041 \le t \le 10^4) — the number of test cases.

The first line of each test case contains a single integer nnn (1≤n≤2⋅1051≤n≤2⋅1051 \le n \le 2 \cdot 10^5).

The second line contains nnn integers a1,a2,…,ana1,a2,…,ana_1, a_2, \dots, a_n (0≤ai≤1090≤ai≤1090 \le a_i \le 10^9).

Additional constraint on the input: the sum of nnn over all test cases doesn't exceed 2⋅1052⋅1052 \cdot 10^5.

Output

For each test case, print a single integer — the number of self-produced subsequences of the array aaa taken modulo 998244353998244353998244353.
