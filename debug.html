F. Paths on a Grid
⏱3 seconds 💾1024 megabytes 2900Grandmaster

You are given a grid aaa of size n×mn×mn \times m. The rows are numbered from 111 to nnn from top to bottom, and the columns are numbered from 111 to mmm from left to right. Each cell of the grid is either blocked or free. Cells (1,1)(1,1)(1, 1) and (n,m)(n,m)(n, m) are free.

A set SSS of cells of aaa, which may include blocked cells, is called good if the following conditions hold:

  • S is non-empty;
  • for every cell (i,j) belonging to S, every path from (1,1) to (n,m) that passes only through free cells, moves one cell down or one cell right at each step, and passes through (i,j) also passes through all other cells of S.

Count the number of good sets of cells of aaa modulo 998244353998 244 353998\,244\,353.

Input

Each test contains multiple test cases. The first line contains the number of test cases ttt (1≤t≤1041≤t≤1041 \le t \le 10^4). The description of the test cases follows.

The first line of each test case contains two integers nnn and mmm (1≤n⋅m≤1061≤n⋅m≤1061 \le n \cdot m \le 10^6).

The iii-th of the following nnn lines contains a string ai,1ai,2…ai,mai,1ai,2…ai,ma_{i, 1} a_{i, 2} \ldots a_{i, m} (ai,j∈{0,1}ai,j∈{0,1}a_{i, j} \in \{0, 1\}) — the iii-th row of the grid. If ai,j=1ai,j=1a_{i, j} = 1, then cell (i,j)(i,j)(i, j) is free; otherwise, it is blocked. It is guaranteed that a1,1=an,m=1a1,1=an,m=1a_{1, 1} = a_{n, m} = 1.

It is guaranteed that the sum of n⋅mn⋅mn \cdot m over all test cases does not exceed 10610610^6.

Output

For each test case, output a single integer — the answer to the problem modulo 998244353998 244 353998\,244\,353.
