B. Nikita and Books
⏱1 second 💾256 megabytes 800Newbie
greedymathsortings

As is well known, Nikita loves reading. Today, he made a mess in his room and arranged his books into nnnn stacks in a row, numbered from 1111 to nnnn from left to right. The iiii-th stack contains aiaiaia_i books. This arrangement is called neat if, in every stack except the rightmost one, the number of books is strictly less than in the stack to its right; that is, the array aaaa is strictly increasing.

Yura wants to make the arrangement neat by performing the following operation any number of times:

  1. Choose a stack ii such that 1≤i1ai>1.
  2. Take 11 book from the top of stack ii, so aiai decreases by 11.
  3. Put this book on top of stack i+1i+1, so ai+1ai+1 increases by 11.

Determine whether Yura can make the arrangement neat.

Input

The first line contains a single integer tttt (1≤t≤1041≤t≤1041≤t≤1041 \le t \le 10^4) — the number of test cases.

The first line of each test case contains a single integer nnnn (1≤n≤2⋅1051≤n≤2⋅1051≤n≤2⋅1051 \le n \le 2 \cdot 10^5) — the number of stacks.

The second line of each test case contains nnnn integers aiaiaia_i (1≤ai≤1091≤ai≤1091≤ai≤1091 \le a_i \le 10^9) — the initial number of books in each stack.

It is guaranteed that the sum of nnnn over all test cases does not exceed 2⋅1052⋅1052⋅1052 \cdot 10^5.

Output

For each test case, output "YES" if Yura can make the arrangement neat, and "NO" otherwise.

You may output each letter in any case (lowercase or uppercase). For example, the strings "yEs", "yes", "Yes", and "YES" will be accepted.
