F. 4-beauty

For a set of integers SSS, define its divisibility characteristic as the number of ordered pairs (x,y)(x,y)(x, y) such that x≠yx≠yx \ne y, xxx and yyy belong to SSS, and xxx is divisible by yyy.

For a set of integers AAA, define its 444-beauty as follows:

  • consider all sets of four distinct numbers that belong to A and form an arithmetic progression;
  • find the maximum divisibility characteristic among all such sets.

If there are no suitable sets of four numbers, then the 444-beauty equals 000.

Initially, the set {1,2,…,n}{1,2,…,n}\{1, 2, \ldots, n\} is given. You may remove numbers from it. Removing the number iii costs mimim_i coins.

Calculate the minimum number of coins you have to spend in order to decrease the 444-beauty of the set.

Input

The first line contains one integer nnn (4≤n≤5⋅1054≤n≤5⋅1054 \le n \le 5 \cdot 10^5) — the number of elements in the initial set.

The second line contains nnn integers m1,m2,…,mnm1,m2,…,mnm_1, m_2, \ldots, m_n (1≤mi≤1091≤mi≤1091 \le m_i \le 10^9), where mimim_i is the cost of removing the number iii.

Output

Print one integer — the minimum number of coins you have to spend in order to decrease the 444-beauty of the set. It can be shown that it is always possible.

Examples
Example 1
Input 
4
5 3 7 2
Output 
2
Note

In the first example, the only arithmetic progression of four numbers is 1,2,3,41,2,3,41, 2, 3, 4. Its divisibility characteristic equals 444. It is sufficient to remove the number 444, paying 222 coins.

In the second example, it is sufficient to remove the number 111.

In the third example, it is optimal to remove the numbers 111 and 666, paying 2+3=52+3=52+3=5 coins.
