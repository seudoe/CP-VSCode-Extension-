B. Good times Good times
⏱1 second 💾256 megabytes 1100Newbie
constructive algorithmsdfs and similarmath

An integer nnnn is said to be good if it contains at most two distinct digits in its decimal representation. For example, the integers 3333, 8588858885888588, 67676767 are good, whereas the integers 123123123123, 9447944794479447 are not.

You are given an integer xxxx (1≤x<1081≤x<1081≤x<1081 \le x \lt 10^8), which is good. Your task is to find an integer yyyy (2≤y≤1092≤y≤1092≤y≤1092 \le y \le 10^9) such that both of the following conditions are satisfied:

  • yy is good.
  • x×yx×y is good.
Input

The first line contains an integer tttt (1≤t≤1041≤t≤1041≤t≤1041 \le t \le 10^4) — the number of test cases. The description of each test case follows.

Each test case contains a single integer xxxx (1≤x<1081≤x<1081≤x<1081 \le x \lt 10^8). It is guaranteed that xxxx is good.

Output

For each test case, print a single integer yyyy (2≤y≤1092≤y≤1092≤y≤1092 \le y \le 10^9) such that both the integers yyyy and x×yx×yx×yx \times y are good.

If there are multiple valid answers, output any one of them.

Note

For the first test case, we have x=8x=8x=8x = 8; choosing y=11y=11y=11y = 11 is valid because both y=11y=11y=11y = 11 and x×y=88x×y=88x×y=88x \times y = 88 are good.
