B. Tatar TV Show

During the holidays, Egor came to visit his friend Dabir in the city of Kazan. Out of boredom, Dabir and Egor came up with a new business idea: to make their own TV show.

The format of the show is very simple: in each episode they invite a guest and play a game with them on a binary string.

In today's episode, Egor and Dabir invited Arseniy (aka MAKAN) — the main celebrity of Omsk. For the game, they chose a binary string ssss of length nnnn and an integer kkkk.

Arseniy can make an unlimited number of moves. In one move, he can choose an integer iiii (1≤i≤n−k1≤i≤n−k1≤i≤n−k1 \le i \le n - k) and invert the characters at positions iiii and i+ki+ki+ki + k, that is, change 0000 to 1111 and 1111 to 0000.

For example, if s=10110s=10110s=10110s = 10110 and k=2k=2k=2k = 2, then by choosing i=2i=2i=2i = 2, Arseniy inverts the characters at positions 2222 and 4444: [10110→11100][10110→11100][10110→11100][ 10110 \rightarrow 11100 ]

Arseniy wants to get the main prize — 100000010000001 000 0001\,000\,000 tugriks. To do this, he needs to make the entire string ssss equal to zero.

Help Arseniy determine whether he can get his prize, or if he will have to return to Omsk with nothing.

Input

The first line contains a single integer tttt (1≤t≤1041≤t≤1041≤t≤1041 \le t \le 10^4) — the number of test cases.

The first line of each test case contains two integers nnnn and kkkk (1≤k≤n≤2⋅1051≤k≤n≤2⋅1051≤k≤n≤2⋅1051 \le k \le n \le 2 \cdot 10^5).

The second line of each test case contains a binary string ssss of length nnnn.

It is guaranteed that the sum of nnnn over all test cases does not exceed 2⋅1052⋅1052⋅1052 \cdot 10^5.

Output

For each test case, output "YES" if Arseniy can make the string entirely zero, and "NO" otherwise.

You can output "YES" and "NO" in any case (for example, "yES", "yes", and "Yes" will be accepted).
